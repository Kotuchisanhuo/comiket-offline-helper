# 夏コミ现场助手 GitHub Pages 包

把本文件夹内的全部文件上传到 GitHub 仓库，然后在仓库 Settings -> Pages 里选择从分支部署即可。

推荐仓库名：`comiket-offline-helper`

发布后地址通常是：

```text
https://你的用户名.github.io/comiket-offline-helper/
```

iPhone 安装：

1. 用 Safari 打开上面的地址。
2. 点分享按钮。
3. 点“添加到主屏幕”。
4. 打开“作为网页 App 打开”。
5. 添加后，从主屏幕图标打开一次，并进入地图页确认图片加载。
6. 关闭网络后再打开测试。

注意：清除 Safari 网站数据或删除主屏幕 App，可能会清掉本地清单。
